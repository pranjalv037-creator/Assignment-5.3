Google Fonts Used


Playfair Display — Used for headings to give them an elegant appearance.

Lato — Used for body text because it is clean and readable.


 CSS Properties Used


• font-family — Selects the font.

• font-size — Changes the size of text.

• font-weight — Controls text thickness.

• text-align — Aligns text left, right, or center.

• text-decoration — Adds underline or other text decoration.

• font-style — Makes text italic or normal.

• letter-spacing — Adjusts the spacing between letters.

• line-height — Adjusts the spacing between lines.
